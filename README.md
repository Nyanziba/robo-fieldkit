# RoboFieldKit（作業タイトル）

ロボット現場作業のためのポケットツールキット PWA。

- **完全クライアントサイド**：バックエンドなし、データは端末内のみ。
- **オフライン対応**：サービスワーカーで全アセットをキャッシュし、電波のない現場でも動作。
- **外部 CDN 依存なし**：素の HTML / CSS / JavaScript のみ。ビルド不要。
- **モバイルファースト**：ダークテーマ、大きなタッチターゲット、日本語 UI。

## 収録ツール（v1）

1. **差動二輪オドメトリ計算器** — 車輪半径・車軸幅・左右エンコーダ値・1回転パルス数から、移動距離・方位角変化・新位置 (x, y, θ) を算出。
2. **クォータニオン ⇄ オイラー角 ⇄ 回転行列** — クォータニオン (x, y, z, w) とロール/ピッチ/ヨー [°]、3×3 回転行列を双方向変換。ライブプレビュー付き。
3. **車輪速度・ギア比変換器** — モーター RPM ↔ 車輪回転数 ↔ 直進速度 (m/s) を車輪径・ギア比から換算。逆算も可能。
4. **CAN フレーム変換** — CAN ID の HEX/DEC 変換、16/32 ビット・リトル/ビッグエンディアン、スケール＋オフセットによる raw→物理値変換。
5. **バッテリー稼働時間推定** — 容量 (Ah) ÷ 平均消費電流 (A) で稼働時間を推定。mAh 簡易消費計算も収録。

## ローカルで動かす

静的サイトなので、任意の静的サーバで配信できます。`file://` 直接起動でも概ね動作しますが、サービスワーカー・マニフェストは HTTP(S) 配信が必要です。

```bash
cd robo-fieldkit
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。他にも Node をお使いなら：

```bash
npx serve .        # または
npx http-server .
```

## GitHub Pages にデプロイ

1. GitHub にリポジトリを作成し、このフォルダの中身を push します。
2. リポジトリの **Settings → Pages** を開き、**Build and deployment** で **Source** を `Deploy from a branch`、ブランチを `main`（または任意）に設定して保存します。
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

相対パス（`./`）を基準にしているため、プロジェクトサイト（`/リポジトリ名/`）配下でもそのまま動作します。

> **オフライン利用のコツ**：一度サイトを開いてサービスワーカーが登録されると、以降はオフラインでも利用できます。スマホでは「ホーム画面に追加」でネイティブアプリのように起動できます。

## 計算の考え方（要点）

- **オドメトリ**：左右の車輪移動距離 `d_L, d_R = 2πr·N/TPR`。平均距離 `d = (d_L + d_R)/2`、方位角変化 `Δθ = (d_R − d_L)/L`。等速直進（`N_L = N_R`）では `Δθ = 0`、`d = 2πr·(N/TPR)`。
- **クォータニオン**：Hamilton 表記 `q = w + xi + yj + zk`。回転順は `R = Rz(yaw)·Ry(pitch)·Rx(roll)`（ZYX 内因性）。
- **車輪速度**：車輪回転数 = モーターRPM ÷ ギア比、速度 = 円周 × 車輪RPM ÷ 60。
- **バッテリー**：稼働時間 [h] = 容量 [Ah] ÷ 消費電流 [A]。
